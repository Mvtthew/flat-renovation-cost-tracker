# AllPlanItemsPage

Full-page list of every planned cost item across all rooms, reached by tapping the "pozycje" [StatBox](../components/StatBox.md) on [HomePage](HomePage.md) (route `/pozycje`). Loads `planItems`, `settings/rooms`, and `settings/shops` from the Realtime Database and renders every plan item sorted by room order then item order, each showing price, tags, room (with its [room icon](../lib/roomIcons.ts)), shop, delivery info, and target date. Rows use [SwipeableRow](../components/SwipeableRow.md) to reveal an edit action that navigates to `/pozycje/:itemId` ([PlanItemFormPage](PlanItemFormPage.md)). Header shows a back arrow (`navigate(-1)`) and a total count/planned-cost summary with a "+ Pozycja planu" button linking to `/dodaj`. `App.tsx`'s `AppShell` hides the bottom tab bar for any `/pozycje*` path, matching the existing behavior for the edit form.

A search `Input` (with a `Magnifier` icon) below the summary row filters the list by case-insensitive substring match against the item's name, its tags, its room's name, or its shop's name — matching any one of those fields is enough to keep the item visible. An empty-search-result state ("Brak pozycji pasujących do wyszukiwania.") is shown separately from the "no plan items at all" empty state.

A `Folders`/`ListUl` `IconButton` next to the "+ Pozycja planu" button toggles local `groupByTagEnabled` state (defaults to `true` — grouped is the default view). When enabled, the (already search-filtered) plan items are grouped via [`groupItemsByTag`](../lib/groupByTag.ts) — items with multiple tags appear once per tag, items with no tags land in a trailing "Bez tagu" group — and each group renders as a Chakra `Collapsible.Root` section with a clickable header (item count, total planned cost for that group, and a `ChevronDown` that rotates -90° when collapsed) followed by the group's rows. Expanded state per tag is tracked in local `expandedGroups` (a `Set<string>`, not persisted, empty by default so all groups start collapsed). Toggling the `IconButton` off switches back to the flat list.
