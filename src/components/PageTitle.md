# PageTitle

Renders a page's heading, left-aligned in `xl` font size. Used at the top of
each tab's page component so every page has a consistent title treatment.

## Props

- `children: string` — the title text (Polish, e.g. "Pokoje").

## Use cases

- Top of `HomePage`, `RoomsPage`, `TimelinePage`, `AddPage`, `SettingsPage`.
